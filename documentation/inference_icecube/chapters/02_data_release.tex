\section{Data structure: event-by-event weighted Monte Carlo}
\label{sec:data-structure}

\begin{theorybox}
Data provenance: \texttt{notebooks/external/icecube/IceCube1\_generator.ipynb}
fetches and validates the release verbatim into
\texttt{data/detector/icecube/raw/}. Four physically distinct interaction
channels are shipped as separate real Monte Carlo event tables --
neutral-current (\code{nc}), electron-neutrino charged-current
(\code{nue\_cc}), muon-neutrino charged-current (\code{numu\_cc}), and
tau-neutrino charged-current (\code{nutau\_cc}) -- each event carrying its
own true energy, true $\cos\theta_z$, PDG code (flavour and
neutrino/antineutrino sign), reconstructed analysis-bin location, and real
physical weight $w_i$ (units GeV~cm$^2$~sr). Separately, the release ships
real per-bin ``hypersurface'' correction tables for 5 detector-calibration
parameters, tabulated at 20 real $\Delta m^2_{31}$ slices
(\cref{ch:detector-implementation}), the real pre-binned atmospheric-muon
background histogram, and the real observed candidate counts.
\end{theorybox}

\begin{resultbox}
This project's own real analysis binning reproduces the release's own
\texttt{readme.md} recipe exactly: 10 log-spaced reconstructed-energy bins
(6.31-158.49~GeV, one internal edge of an original 11-bin log grid merged
away by the release's own authors ``to contain sufficient statistics''),
10 linear $\cos\theta_z$ bins ($-1.0$ to $0.1$), and 2 particle-ID bins
(tracks only, the cascade-like bin is not part of this release) -- 200
bins total. The real (downsampled $\times10$ for computational
tractability, weights rescaled to compensate so the expectation stays
unbiased) event counts per channel: \code{nc}: 2535, \code{nue\_cc}: 3995,
\code{numu\_cc}: 28{,}517, \code{nutau\_cc}: 4640. Real observed total:
\textbf{21{,}914} events; real Monte Carlo muon-background total:
\textbf{512.2} events -- both facts about the data itself, reproduced
exactly by this project's loaders regardless of any fit.
\end{resultbox}
